# CSplugins
Плагины для серверов CS:GO.

---

## CheaterTeleport **EN**

Administrative plugin for CS:GO that manages a “cheater zone” on the server.  
Adds a dedicated section to the Admin Menu and automates handling of flagged players.

### Features
- Add a player to the cheater list  
- Remove a player from the list  
- View all flagged players  
- Set teleport coordinates for the current map  
- Select players via menu (no SteamID input required)  
- Automatic teleport + weapon removal on spawn  

### Commands (via Admin Menu)
- `sm_addcheater` — add cheater  
- `sm_removecheater` — remove cheater  
- `sm_listcheaters` — list cheaters  
- `sm_setcheaterpos` — save teleport position  

### Compatibility
- **CS:GO only**  
- SourceMod 1.12  
- Full Admin Menu integration

## CheaterTeleport **RU**


Плагин для администраторов CS:GO, позволяющий управлять «читерской зоной» на сервере.  
Добавляет отдельный раздел в Admin Menu и автоматизирует работу с игроками, отмеченными как нарушители.

### Возможности
- Добавление игрока в список читеров  
- Удаление игрока из списка  
- Просмотр списка читеров  
- Установка точки телепорта на карте  
- Выбор игрока через меню (без ввода SteamID)  
- Автоматический телепорт и разоружение отмеченных игроков при спавне  

### Команды (через Admin Menu)
- `sm_addcheater` — добавить читера  
- `sm_removecheater` — удалить читера  
- `sm_listcheaters` — список читеров  
- `sm_setcheaterpos` — сохранить точку телепорта  

### Совместимость
- **Только CS:GO**  
- SourceMod 1.12  
- Полная интеграция с Admin Menu
